## Problem

A team writing notes or documentation needs to group them by topic, give everyone the right level of access (read, edit, admin) and comment in the same place. I built this application without a framework, as a deliberate choice: writing the router, middleware and data access by hand.

## My contribution

Built solo from March to June 2026: backend, API, frontend, database schema, tests and containerization.

## Solution

**For workspace owners**

- Create workspaces and pages.
- Invite members with a role: viewer, editor or admin.
- Share a page as read-only or editable, and moderate comments.

**For every user**

- Dashboard: workspaces, pages, comments, collaborators and recent activity.
- Comments on pages; only the author can edit their own.
- Profile with avatar (JPG, PNG, GIF or WebP, 5 MB max, type checked on the server).

### Architecture

<Diagram />

Every request goes through `public/index.php`. A regular-expression router maps each route to a controller, after the authentication middleware. Controllers validate input and return explicit HTTP status codes; models contain only the SQL queries. In the browser, `state.js` holds the state, `ui.js` renders and `api.js` calls the API.

The schema links `users`, `workspaces`, `workspace_members`, `pages`, `page_shares` and `comments`. Deleting a workspace cascades to its pages, comments, members and shares.

### Security

- Passwords hashed with `password_hash` (bcrypt).
- PDO prepared statements for every database access.
- `session_regenerate_id()` after sign-in.
- Identical sign-in error message for an unknown email and a wrong password.
- Access control on every route: authentication, resource existence, user permissions.

### Testing and quality

23 PHPUnit integration tests send real HTTP requests to a dedicated database: authentication, workspaces, collaboration and page sharing, including denied cases (access without a session, non-member user, read-only share).

Latest run (PHPUnit 12.5, PHP 8.3, November 14, 2026): 23 tests and 60 assertions, all passing.
