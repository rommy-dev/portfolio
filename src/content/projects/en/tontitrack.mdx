## Problem

A tontine runs on trust: every member contributes each cycle, and members take turns receiving the pot. When tracking happens on paper or in a spreadsheet, the organizer recalculates late payments, debts and penalties by hand. A mistake fixed by overwriting a value wipes out the original information, and nobody can check how a balance was reached.

## My contribution

Personal project built solo, from April to September 2026 (162 commits): data modeling, Express API, React interface, tests, Docker containerization and deployment on Render.

## Solution

**For the group organizer**

- Create groups, members and contribution cycles.
- Late penalties applied by a scheduled job.
- Transaction corrections recorded as reversal and replacement entries, visible in the history.
- PDF export of a cycle and Excel export of a group.

**For members**

- Track your contributions, your debts and your transaction history.
- Reminders before due dates and late-payment alerts as in-app notifications, with amounts shown in your chosen currency.

### Architecture

<Diagram />

The API follows a controller → service → model split: the controller validates the request, the service holds the business rules (debt calculation, offsetting entries), and the model describes the Mongoose schema. Cron jobs run in the same process as the API: closing expired cycles, applying penalties, 3-day reminders, late-payment alerts and notification cleanup.

### Security

- JWT access token and refresh token stored in an `httpOnly` cookie, rotated on every refresh.
- HTTP headers via Helmet, restricted CORS, rate limiting on the API and on authentication routes.
- Transaction corrections restricted to the group admin, checked in the service layer.

### Testing and quality

Integration tests run against an in-memory MongoDB database (MongoMemoryServer), with no connection to Atlas. They cover authentication, groups and contributions; unit tests cover the financial calculations. Tests do not run in continuous integration: they are run by hand.
