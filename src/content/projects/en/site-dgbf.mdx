## Problem

The Directorate General of Budget and Finance publishes information for the public: budget documents, laws and decrees, the budget calendar, news. This content has to be easy for citizens to find and easy for staff to update.

Before the redesign, the site was slow, its design was dated, and every content update had to go through a developer.

## My contribution

Internship at the DGBF from January to February 2026 (first commit on January 8, last code commit on February 28), in a team of 4: 2 developers (including me), a supervisor and a designer. The stack (Laravel with Sanctum) was set by the DGBF.

I took part in the whole build of the site: public pages, admin console, REST API and authentication. The site has been modified by others since I left, so the live version is no longer exactly the one delivered during the internship.

## Solution

**For citizens and partners**

- Library of budget documents with filters and search.
- Regulatory texts grouped by directorate, readable online.
- Budget statistics as charts.
- Org chart of the directorates and budget calendar.

**For DGBF staff**

- Protected admin console to publish documents, texts, news, videos and FAQs.

## Results

No usage data has been shared. The portal was delivered and put live; staff can publish documents and news from the admin console, without a developer.

### Architecture

<Diagram />

The Laravel 11 backend exposes a REST API and manages data with Eloquent. The Vue 3 frontend, written in TypeScript, consumes that API. Content is organized into entities (directorates, budget documents and texts with their categories, articles, videos, calendar events, FAQs).

### Security

Admin routes are protected by Laravel Sanctum.

### Testing and quality

No project-specific automated tests.
